# Task 3 - Forward Deployed Engineer Assessment

Author: Aryabrat Mishra

## Submission boundary

The assessment deliverables are a case-study PDF, a one-page procurement note and completed written form answers. They contain confidential assessment context and are supplied separately through the authorised application channel. This public repository intentionally does not contain the client notes, client-specific proposal, private measurements or commercial assumptions.

## General approach

A manufacturing correction proposal should establish repeatable measurements, supported machine controls and an experimentally measured response before recommending input changes. Human approval, traceable recipe versions, a rollback path and a prospective evaluation are essential. Physical quality validation remains necessary.
